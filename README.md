# CURSEBOUND — «Оковы Тьмы»

Тёмное фэнтези · idle RPG clicker. Чистые HTML + CSS + JavaScript, без сборщиков,
фреймворков и зависимостей. Игра запускается открытием `index.html` в браузере.

Ни одного внешнего запроса: шрифты лежат в `css/fonts/`, поэтому игра
одинаково работает и с `file://`, и без сети.

Сохранение: `localStorage`, ключ `cursebound_save_v5`. Ключи `v1`–`v4` читаются и
мигрируют автоматически.

## Ключевые правила систем

**Редкость предметов.** Пять ступеней: Обычная → Редкая → Эпическая → Легендарная →
Мифическая. Диапазоны множителей статов (`RAR[i].lo/hi`) **не пересекаются**, поэтому
мусор физически не может нести статы высокой ступени. Пул имён тоже привязан к
редкости (`RAR_PREFIX`), мифические носят собственные имена (`MYTHIC_NAMES`).
Источник задаёт коридор: Владыки и меченые — не ниже эпической, обычные твари —
не выше эпической, мифика — только с Владык/меченых и с глубины 60.
Осквернение (проклятие в горне) — отдельный флаг `cursed`, поэтому названия
«Проклятая Проклятая» больше не бывает.

**Усталость руки.** До 11 кликов/сек — без штрафа (человек редко выдаёт больше 9).
Выше — копится `fatigue`, срезающая до 85% урона клика; выше 22 кликов/сек удары
просто не проходят. Восстановление — 0.4 в секунду.

**Порог престижа.** Считается по `S.runMax` — максимальной глубине **текущего**
забега, который обнуляется после Разрыва. Порог растёт: `45 + 10 × prestige`.
Дополнительно действует остывание `PREST_COOLDOWN` (10 минут).

**Кривая глубины.** `depthCurve(s)` — ступенчатая: 1.16 до 40, 1.135 до 120, 1.105
дальше. HP твари на глубине 200 — около 3.4×10¹¹, поэтому проходимость глубины
200+ обеспечивается не самой кривой, а мультипликативным ядром лавки.

**Мультипликативное ядро.** `blade`/`servant` растут линейно, а HP — экспоненциально.
Чтобы забег не упирался в стену «золото есть, силы нет», в лавке три товара с
множителем: «Пробуждение Оков» (+12%), «Эхо Бездны» (+13%) и «Корона Глубин» (+14%)
за уровень, `×` друг на друга. Цены растут быстрее дохода (`g` = 1.50 / 1.62 / 1.75),
так что это ограниченное, но постоянное ускорение.

**Владыки.** HP Владыки — `BOSS_HP_MULT` (7) × HP обычной твари, на убийство
`BOSS_TIME` (40 с). Исторические 10×/30 с требовали на 100-й глубине ~3 млн DPS,
а сила той эпохи давала ~0.6 млн — Владыка становился непроходимым навсегда.

**Мягкий закон глубин.** Первые две неудачи на Владыке отбрасывают на этаж назад.
С третьей попытки (`S.bossTries`) откат прекращается: игрок остаётся на глубине,
фармит и возвращается сильнее. Это убирает «висящий» забег, из которого нельзя
было выйти иначе как через слепой фарм.

**Закрытые формулы цен.** `bulkCost` при `n ≤ 400` считает точную сумму уровней,
выше — по геометрической прогрессии; `maxAfford` решает неравенство логарифмом
и уточняет на ±2 шага. Раньше «Макс» молча упирался в 500 уровней и вызывал
`bonuses()` тысячи раз за один рендер лавки.

**Режимы.** `S.mode` = `deeper` (глубина растёт с каждым убийством) или `farm`
(держится на месте). Переключается на вкладке «Карта» и клавишей `T`.

## Проверки

Игра запускается без сборки, но проверки — это обычный `node`:

```
npm install          # jsdom + eslint (только для разработки)
npm test             # тесты: формулы, сейвы, вкладки, инварианты баланса
npm run lint         # опечатки в именах, дубли ключей
npm run test:balance # симуляция 10 забегов на реальном коде
```

`tools/test.js` собирает все скрипты в одну область (как браузер), грузит игру
в jsdom и проверяет:

| Блок | Что проверяется |
|---|---|
| Формулы | `nf()` на 1e33+, монотонность `depthCurve`, `bulkCost == Σ upgCost`, корректность `maxAfford` |
| Интеграция | клики, тики, все 10 вкладок, покупка всех товаров, экспорт/импорт сейва |
| Сейвы | 24 варианта мусора: битый JSON, `gold: null`, `stage: 1e9`, предметы с `rar: 99`, старые `v1`/`v4` |
| Баланс | сила растёт нелинейно по золоту, Владыку на 100 можно снять |
| Производительность | `maxAfford` ×1000 и 1000 тиков укладываются в лимиты |
| Целостность | все ссылки на файлы и `url()` в CSS живут, `.woff2` валидны, нет дублей `id`, порядок скриптов верный |
| Офлайн | `index.html` грузится с реальной загрузкой ресурсов: 0 запросов наружу, 0 исключений |

Все игровые имена живут в глобальной области (нужно для `file://`), поэтому
после добавления новой функции верхнего уровня перезапустите
`node tools/gen-eslint-globals.js`, иначе линтер начнёт ругаться на `no-undef`.
Для тестов и консоли есть один явный вход — `window.CB`.

## Точки расширения

| Что добавить          | Где                                                |
|-----------------------|-----------------------------------------------------|
| Бонус/множитель       | `combat.js` → `bonuses()`                            |
| Предмет лавки         | `shop.js` → `SHOP` (+ id в `DEF().shopOrder`)        |
| Узел древа            | `skills.js` → `SK_COMMON` / `SK_CLASS`               |
| Узел престижа         | `prestige.js` → `PGROUPS`                            |
| Фамильяр              | `pets.js` → `PETS` + силуэт в `PET_SVG`              |
| Рецепт горна          | `craft.js` → `ELIXIRS` / `OILS` / `INKS`             |
| Регион и его закон    | `map.js` → `BASE_ZONES` / `HIDDEN_ZONES`, читает `ZR()` |
| Тип предмета/слот     | `inventory.js` → `ITYPE`, `SLOTS`, `STAT_POOL`, имена |
| Активность            | `city.js` → `RITUALS` / `CTASKS` / `EXPS`            |
| Достижение / завет    | `hidden.js` → `ACH` / `GOALS`                        |
| Поле сохранения       | `state.js` → `DEF()` **и** `migrate()`               |
| Кланы / соцсистема    | `clans.js` (пустая заготовка) + поле в `migrate()` + вкладка |

**Про `clans.js`.** Файл намеренно пуст: игра одиночная и оффлайн, сервера нет.
Кланы в оффлайн-игре возможны только как локальная имитация («орден», который
растёт от твоих же действий), поэтому это **продуктовое решение**, а не
технический долг. Пока его нет, пустой файл не стоит держать в сборке — в
`index.html` он закомментирован, и на загрузку страницы это не влияет.
