# CURSEBOUND — «Оковы Тьмы»

Тёмное фэнтези · idle RPG clicker. Чистые HTML + CSS + JavaScript, без сборщиков,
фреймворков и зависимостей. Игра запускается открытием `index.html` в браузере.

Сохранение: `localStorage`, ключ `cursebound_save_v5`. Ключи `v1`–`v4` читаются и
мигрируют автоматически.

## Ключевые правила систем

**Редкость предметов.** Пять ступеней: Обычная → Редкая → Эпическая → Легендарная →
Мифическая. Диапазоны множителей статов (`RAR[i].lo/hi`) **не пересекаются**, поэтому
мусор физически не может нести статы высокой ступени. Пул имён тоже привязан к
редкости (`RAR_PREFIX`), мифические носят собственные имена (`MYTHIC_NAMES`).
Источник задаёт коридор: Владыки и меченые — не ниже эпической, обычные твари —
не выше эпической, мифика — только с Владык/меченых и с глубины 60.
Осквернение (проклятие в горне) — отдельный флаг `cursed`, поэтому названия
«Проклятая Проклятая» больше не бывает.

**Усталость руки.** До 11 кликов/сек — без штрафа (человек редко выдаёт больше 9).
Выше — копится `fatigue`, срезающая до 85% урона клика; выше 22 кликов/сек удары
просто не проходят. Восстановление — 0.4 в секунду.

**Порог престижа.** Считается по `S.runMax` — максимальной глубине **текущего**
забега, который обнуляется после Разрыва. Порог растёт: `45 + 10 × prestige`.
Дополнительно действует остывание `PREST_COOLDOWN` (10 минут).

**Кривая глубины.** `depthCurve(s)` — ступенчатая: 1.16 до 40, 1.135 до 120, 1.105
дальше. Ранняя игра медленнее, но глубина 200+ остаётся проходимой.

**Режимы.** `S.mode` = `deeper` (глубина растёт с каждым убийством) или `farm`
(держится на месте). Переключается на вкладке «Карта» и клавишей `T`.

## Точки расширения

| Что добавить          | Где                                                |
|-----------------------|-----------------------------------------------------|
| Бонус/множитель       | `combat.js` → `bonuses()`                            |
| Предмет лавки         | `shop.js` → `SHOP` (+ id в `DEF().shopOrder`)        |
| Узел древа            | `skills.js` → `SK_COMMON` / `SK_CLASS`               |
| Узел престижа         | `prestige.js` → `PGROUPS`                            |
| Фамильяр              | `pets.js` → `PETS` + силуэт в `PET_SVG`              |
| Рецепт горна          | `craft.js` → `ELIXIRS` / `OILS` / `INKS`             |
| Регион и его закон    | `map.js` → `BASE_ZONES` / `HIDDEN_ZONES`, читает `ZR()` |
| Тип предмета/слот     | `inventory.js` → `ITYPE`, `SLOTS`, `STAT_POOL`, имена |
| Активность            | `city.js` → `RITUALS` / `CTASKS` / `EXPS`            |
| Достижение / завет    | `hidden.js` → `ACH` / `GOALS`                        |
| Поле сохранения       | `state.js` → `DEF()` **и** `migrate()`               |

## Горячие клавиши

`Пробел` — удар · `1` `2` — умения · `3` — ультиматив · `Z` — стойка · `T` — фарм/глубже
`Q` `W` `E` — зелья · `R` — Колодец · `M` — звук · `Esc` — закрыть окно
`H` герой · `C` кодекс · `B` лавка · `X` карта · `G` горн · `K` путь · `F` свита · `I` сумка · `D` дела · `P` тьма
